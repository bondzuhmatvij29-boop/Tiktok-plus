# TikTok Clone - Повнофункціональний клон

Повноцінний клон TikTok з усіма основними функціями, створений на React, TypeScript, Tailwind CSS та Vite.

## 🎯 Функціонал

### 📱 Головна стрічка (Home)
- Вертикальний скрол відео у повноекранному режимі
- Автоматичне відтворення відео при скролі
- Пауза/відтворення при натисканні на відео
- Лайки з анімацією
- Коментарі з модальним вікном
- Кнопка підписки на автора
- Відображення кількості переглядів, лайків, коментарів
- Інформація про музику/звук

### 👤 Профіль (Profile)
- Статистика користувача (підписники, підписки, вподобання)
- Сітка відео користувача
- Вкладки: Відео, Вподобання (приватні), Збережені
- Кнопка підписки/відписки
- Можливість редагування власного профілю
- Верифікований значок для підтверджених акаунтів

### 💬 Повідомлення (Messages)
- Список чатів з передостаннім повідомленням
- Позначки непрочитаних повідомлень
- Повноцінний чат з історією повідомлень
- Відправка текстових повідомлень
- Пошук по чатам
- Кнопки для аудіо та відео дзвінків

### 🔍 Пошук (Search)
- Пошук по відео, користувачам, хештегам
- Фільтри: Все, Користувачі, Відео, Хештеги, Музика
- Трендові хештеги з кількістю переглядів
- Рекомендовані акаунти
- Результати пошуку у вигляді сітки з превью

### 📡 LIVE трансляції (Live)
- Перегляд активних прямих ефірів
- Відображення кількості глядачів
- LIVE значок з анімацією
- Статистика активних трансляцій
- Інструкція як почати власний ефір
- Можливість взаємодії (лайки, коментарі, подарунки)

### ⬆️ Завантаження контенту (Upload)
- Вибір типу контенту (відео або фото)
- Завантаження файлів або drag & drop
- Попередній перегляд перед публікацією
- Додавання опису до 150 символів
- Вибір музики/звуку
- Додавання хештегів
- Налаштування приватності (публічний, тільки друзі, приватний)
- Поради для кращого контенту

### 🧭 Навігація
- Адаптивна навігаційна панель (внизу на мобільних, вгорі на десктопі)
- 6 основних розділів з іконками
- Виділення активного розділу
- Плавні переходи між сторінками

## 🎨 Дизайн

- Темна тема у стилі TikTok
- Градієнти (pink-purple-blue)
- Анімації та плавні переходи
- Адаптивний дизайн для мобільних та десктопних пристроїв
- Сучасний UI з використанням Lucide іконок

## 🛠️ Технології

- **React 18** - UI бібліотека
- **TypeScript** - типізація
- **Vite** - швидкий білд та dev сервер
- **Tailwind CSS** - utility-first CSS
- **React Router** - маршрутизація
- **Lucide React** - іконки
- **Context API** - управління станом

## 🚀 Як користуватися

1. **Головна сторінка** - скрольте відео вгору/вниз
2. **Лайкайте** - натискайте на іконку серця
3. **Коментуйте** - натискайте на іконку коментарів
4. **Підписуйтесь** - натискайте кнопку "Підписатись"
5. **Завантажуйте** - перейдіть у розділ "Додати" та оберіть файл
6. **Пишіть повідомлення** - відкрийте розділ "Повідомлення"
7. **Шукайте** - використовуйте розділ "Пошук"
8. **Дивіться LIVE** - перегляньте активні трансляції

## 📦 Структура проекту

```
src/
├── components/
│   └── Navigation.tsx      # Навігаційна панель
├── pages/
│   ├── Home.tsx           # Головна стрічка відео
│   ├── Profile.tsx        # Профіль користувача
│   ├── Messages.tsx       # Повідомлення
│   ├── Search.tsx         # Пошук
│   ├── Live.tsx           # LIVE трансляції
│   └── Upload.tsx         # Завантаження контенту
├── context/
│   └── AppContext.tsx     # Глобальний стан
└── App.tsx                # Головний компонент
```
